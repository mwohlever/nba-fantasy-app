## Implemented experience

NBA/NFL draft browsing, player research, roster/player view modals and the shared `/player-history` route now use the same Player Center profile and data contracts. Golf keeps its existing components. The separate live football Game Center keeps its live-game workflow; it was already based on actual game data, not this projection-heavy research UI.

- Game log is the default tab. NBA columns include minutes, points, rebounds, assists, steals, blocks, turnovers, and made/attempted FG, 3PT and FT. NFL columns adapt to QB/RB/WR/TE/K/D/ST. Final/live/scheduled/DNP/unverified states remain distinct. Unknown venue, opponent or statistics stay unknown. DNP is never inferred from absence.
- Compact name/team/position/header, exact professional season selector, existing headshot/initials fallback, last-game performance and verified comparison samples. Jersey is supported if a caller supplies a verified value; the current catalog does not supply it, so it is omitted.
- Game Log summaries default to **Season** and reset to Season when the player or selected season changes. Last game / Last 3 / Last 5 / Season comparisons use the foundation's completeness/freshness gates. A two-game season does not manufacture a Last 5 average. Season stats preserve exact regular-season rows, percentages and separate team splits. Previous seasons can be selected; unavailable seasons are explicit.
- Fantasy tab plots actual completed-game fantasy trends, oldest to newest, with Last 5 / Last 10 / Season filters, a dashed average, compact average/high/low metrics and accessible point details. The former single-game contribution/formula layout has been replaced. Scores retain sample sizes and context (frozen slate snapshot / current Group / legacy defaults). Existing canonical scorers are reused. It never rewrites saved historical fantasy outcomes. Unknown fumbles or another required field withhold the total. Kickers retain real FG/PAT/kicking-point columns and have no invented fantasy total.
- Modals support Escape, backdrop dismissal, focus trapping/restoration and body scroll locking. Shared profile panels have unique accessible tab IDs and arrow/Home/End keyboard navigation. Tables scroll inside their containers with sticky game/player columns.
- Draft research preserves the parent eligibility, available/drafted status, position/slot filters, fixed-target pick, correction, ownership, roster and selection callbacks. Normal player selection opens the established draft modal with the shared profile and roster actions in one click; Info opens research. Controls show requested window/metric/direction, sample counts and whether ranking is actually allowed. Missing values do not become zero. Stat sorting is blocked until the entire relevant source pool passes coverage checks; extra legacy draft rows absent from the comparison catalog also block a purported complete ranking. Name search/filtering remains available.
- The full History view offers the research catalog, expanded profile and a return path to existing **111 Sports draft history**. The old season/projection history mode is only offered for Golf. Exact selected local IDs are retained in the URL; sport checks prevent a persisted different sport from reinterpreting a deep-linked player ID. On mobile a selected profile replaces the catalog with an explicit Back to players action.

## Data sources and limits

Normal profiles use the existing authenticated `/api/player-center` GET, reviewed local/provider IDs and bounded ESPN game-log/season-stat/summary reads. Passing a slate ID authorizes that Group/slate and uses its frozen rules. Otherwise the current Group's scoring is explicitly labeled. Raw provider facts may be cached/shared; scoring is computed per authorized context.

Draft comparison GETs use stored observations through `/api/player-center/comparisons`, **zero per-player ESPN fanout**, bounded catalog/history caches and the existing pool coverage gate. The October 26 local integration adds an explicit reader for the separately proposed durable cache; its production schema/population remain unexecuted. New shared presentation and deterministic comparison helpers do not change canonical scoring.

The verified production limitations from the foundation/rollout still apply: 367/530 active NBA mappings are reviewed in production; 98 prepared candidates remain unapplied, 65 remain unresolved. There were zero stored NBA 2027 observations at audit time, so normal current-season draft rankings will remain unavailable. NFL stored offense observations lack independently verified complete season coverage; unknown scoring fields and unsupported kicking/D/ST storage remain explicit. Opening a correctly mapped individual profile can obtain current/prior data even when full-pool sorting is gated. Provider budgets can leave older NFL game summaries incomplete. Verified bye metadata is available from D/ST team schedules; ordinary athlete-log omissions do not establish a bye or DNP. No scoreboard win/loss is invented when the contract only verifies status.

Caching remains the foundation's process-local bounded cache: up to 128 provider entries, 15-minute current-season / 24-hour prior-season TTL, shared in-flight requests, short failure cooldowns, stale-data indicators, three concurrent cold requests and 40 cold requests/minute per process. Each profile has an eight-read / 18-second budget with bounded provider response size/timeouts. Catalog reads cache for one minute and stored history for five minutes. This is appropriate for four people, not a distributed cache guarantee across server instances. Durable cache reads are implemented locally; schema creation and ingestion still require separate rollout approval.
